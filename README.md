# Записная книжка контактов

Мобильное приложение для хранения, поиска, импорта и экспорта контактов.

**Исполнитель:** Свиридова Диана Алексеевна, группа ф3.405с9-1  
**Форма работы:** индивидуально  

## Основные возможности

- Создание, просмотр, редактирование и удаление контактов
- Поиск по имени, фамилии, телефону
- Валидация данных (имя, телефон)
- Локальное хранение в SQLite (дни 4–5)
- Импорт и экспорт в CSV (дни 4–5)

## Стек

- Язык: Kotlin  
- Среда разработки: Android Studio  
- Платформа: Android  
- БД: SQLite (с дня 4)  
- Файлы: работа с файлами CSV на Kotlin (с дня 4–5)  
- Контроль версий: Git
