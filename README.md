# Записная книжка контактов

Мобильное приложение для хранения, поиска, импорта и экспорта контактов.

**Исполнитель:** Свиридова Диана Алексеевна, группа ф3.405с9-1  
**Форма работы:** индивидуально  

## Основные возможности

- Создание, просмотр, редактирование и удаление контактов
- Поиск по имени, фамилии, телефону
- Валидация данных (имя, телефон)
- Локальное хранение в CSV
- UI-прототип на Jetpack Compose (Day 6)

## Стек

- Язык: Kotlin  
- Среда разработки: Android Studio  
- Платформа: Android
- UI: Jetpack Compose + Material 3  
- Хранение: CSV  
- Контроль версий: Git

## Запуск UI-прототипа (Day 6)

1. Открыть проект в **Android Studio**.
2. Дождаться синхронизации Gradle.
3. Выбрать эмулятор (API 26+) или устройство.
4. Run `app`.
5. Проверить сценарии:
   - пустой список;
   - добавление контакта (с валидацией);
   - поиск;
   - просмотр деталей;
   - редактирование;
   - удаление.
