# Обработка ошибок слоя данных
## Дни 4–5 · «Записная книжка контактов»
**Исполнитель:** Свиридова Диана Алексеевна

### Таблица ошибок и реакций

| № | Ситуация | Где возникает | Реакция системы | Сообщение / поведение |
|---|----------|---------------|-----------------|------------------------|
| 1 | Файл не существует | `loadAll()` | Возвращается пустой список | Нет исключения, работа продолжается с пустыми данными |
| 2 | Пустой файл | `loadAll()` | Возвращается пустой список | Аналогично п.1 |
| 3 | Нет прав на чтение | `loadAll()` | `Result.failure` | «Нет прав на чтение файла: …» |
| 4 | Нет прав на запись | `save()` / `writeAll()` | `Result.failure` + откат в памяти | «Нет прав на запись в файл: …» |
| 5 | Неверный формат CSV | `parseLine()` | `Result.failure` | «Неверный формат строки N: ожидалось 6 полей…» |
| 6 | Неверный createdAt | `parseLine()` | `Result.failure` | «Неверный createdAt в строке N» |
| 7 | Пустые обязательные поля в файле | `parseLine()` | `Result.failure` | «Пустые обязательные поля в строке N» |
| 8 | Ошибка сохранения при create/update | `ContactService` | Откат изменений в памяти + `ServiceResult.Fail` | «Не удалось сохранить контакт: …» |
| 9 | Ошибка удаления из хранилища | `ContactService.delete` | Попытка восстановить контакт + `ServiceResult.Fail` | «Не удалось удалить из хранилища: …» |
| 10 | Контакт не найден | `update` / `delete` | `ServiceResult.Fail` | «Контакт не найден» |
| 11 | Ошибка валидации | `ContactValidator` | `ServiceResult.Fail` | Текст конкретной ошибки валидации |

### Принципы обработки

1. **Никаких «голых» исключений** наружу из слоя данных — всё заворачивается в `Result` / `ServiceResult`.
2. **Ресурсы закрываются** через `use`.
3. **Откат при ошибке записи** — память и файл остаются согласованными.
4. **Понятные сообщения** на русском языке для пользователя/лога.
5. **Логирование** критических ошибок загрузки при старте сервиса (`System.err`).

### Пример кода обработки

```kotlin
val saveResult = repository.save(contact)
if (saveResult.isFailure) {
    contacts.remove(contact)
    return ServiceResult.Fail(
        "Не удалось сохранить контакт: ${saveResult.exceptionOrNull()?.message}"
    )
}
```

### Проверенные сценарии в MainDemo

- Несуществующий путь → пустой список
- Битый CSV → failure
- Пустой файл → пустой список
- Успешный цикл «записать → новый сервис → прочитать»
