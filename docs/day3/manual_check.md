# Результаты ручной проверки ядра
## День 3 · «Записная книжка контактов»
**Исполнитель:** Свиридова Диана Алексеевна  
**Язык:** Kotlin · **Среда:** Android Studio

### Как запускать проверку

1. Открыть проект в **Android Studio**.
2. Открыть файл `src/MainDemo.kt`.
3. Нажать Run → Run 'MainDemo'.

В консоли появятся строки `[OK]` / `[FAIL]` по каждому сценарию.

| № | Сценарий | Ожидание | Результат |
|---|----------|----------|-----------|
| 1 | Пустое имя при создании | Ошибка валидации | OK |
| 2 | Имя «Анна» | Валидация проходит | OK |
| 3 | Телефон из 5 цифр | Ошибка («не меньше 10 цифр») | OK |
| 4 | Телефон `+7 999 123-45-67` | Валидация проходит | OK |
| 5 | Создать контакт «Анна Иванова» | Контакт добавлен, есть id | OK |
| 6 | Создать «Борис» без фамилии | Контакт добавлен | OK |
| 7 | Создать с пустым именем | Операция отклонена | OK |
| 8 | В списке 2 контакта | `count == 2` | OK |
| 9 | Поиск «анн» | Найдена Анна | OK |

### Соответствие Must из ТЗ

- Создание контакта  
- Редактирование контакта  
- Удаление контакта  
- Поиск по имени/фамилии/телефону  
- Валидация имени  
- Валидация телефона  

### Замечания

- Хранение пока **в памяти** (`MutableList`). После перезапуска данные пропадут - это нормально для дня 3.  
- SQLite и CSV подключаются в дни 4-5.  
- UI (экраны в Android Studio) - день 6.  

### Вывод

Ядро на Kotlin реализует все обязательные операции. Валидация отсекает некорректные данные. Можно переходить к слою данных (SQLite).
