# Баг-репорты — Day 7
## Записная книжка контактов



### BUG-01. Ошибка записи CSV: Permission denied (EACCES)

| Поле | Значение |
|------|----------|
| **ID** | BUG-01 |
| **Серьёзность** | **Critical** |
| **Статус** | **Fixed** |
| **Окружение** | Android Emulator API 37, приложение 1.0-day6 |
| **Шаги воспроизведения** | 1. Открыть форму добавления<br>2. Ввести имя и телефон (10+ цифр)<br>3. Нажать «Сохранить» |
| **Ожидаемый результат** | Контакт сохраняется, возврат к списку |
| **Фактический результат** | Сообщение: `Не удалось сохранить контакт: data/contacts.csv: open failed: EACCES (Permission denied)` |
| **Причина** | `CsvContactRepository` по умолчанию пишет в относительный путь `data/contacts.csv`, недоступный для записи на Android |
| **Исправление** | В `ContactApp` создавать репозиторий с путём `File(context.filesDir, "contacts.csv").absolutePath` |
| **Повторный прогон** | После исправления сохранение проходит успешно |

### BUG-02. Запуск старого APK / «Hello Android!» вместо UI контактов

| Поле | Значение |
|------|----------|
| **ID** | BUG-02 |
| **Серьёзность** | **Blocker** (на этапе настройки) |
| **Статус** | **Fixed** |
| **Окружение** | Android Studio, проект My Application |
| **Шаги** | 1. Run app на эмуляторе |
| **Ожидаемый результат** | Экран «Контакты» |
| **Фактический результат** | Экран «Hello Android!» |
| **Причина** | Код UI не был в `app/src/main/java`; запускался шаблонный MainActivity пакета `com.example` |
| **Исправление** | Перенос исходников в `app/src/main/java`, манифест → `com.contactnotebook.MainActivity`, Clean/Rebuild, uninstall старого APK |

### BUG-03. (Minor) Список не обновляется после возврата с формы без явного refresh

| Поле | Значение |
|------|----------|
| **ID** | BUG-03 |
| **Серьёзность** | Minor |
| **Статус** | Open / Accepted |
| **Описание** | В `ContactListScreen` список берётся в `remember { service.getAll() }`; при возврате с формы после сохранения может потребоваться пересоздание composition. На практике после `popBackStack` экран часто обновляется, но явного `LaunchedEffect` на resume нет. |
