# Тест-план - Day 7
## Приложение «Записная книжка контактов»

**Исполнитель:** Свиридова Диана Алексеевна  
**Дата:** 25.11.2026  
**Версия ПО:** 1.0 day7  

---

## 1. Цель тестирования

Проверить корректность работы мобильного приложения «Записная книжка контактов»:
- CRUD-операции: создание, просмотр, редактирование, удаление;
- валидация ввода;
- поиск;
- пустые состояния;
- сохранение данных CSV;
- устойчивость к граничным значениям.

## 2. Объект тестирования

| Компонент | Описание |
|-----------|----------|
| UI | Jetpack Compose: список, форма, детали |
| ContactService | Бизнес-логика |
| ContactValidator | Валидация имени и телефона |
| CsvContactRepository | Хранение в CSV |

## 3. Окружение

| Параметр | Значение |
|----------|----------|
| ОС | Android |
| Эмулятор | Medium Phone API 37.0 |
| minSdk | 26 |
| IDE | Android Studio |
| Язык тестов | Kotlin + JUnit |

## 4. Виды тестирования

1. **Функциональное** чёрный ящик — UI и сценарии пользователя.
2. **Граничные значения** - пустой ввод, длинные строки, 9/10/15/16 цифр телефона.
3. **Негативное** — невалидные данные, удаление несуществующего.
4. **Unit-тесты** — ContactValidator, ContactService (create/update/delete/search).

## 5. Объём работ

- Тест-план (этот документ)
- 10 тест-кейсов
- Ручной прогон на эмуляторе
- Баг-репорты
- Unit-тесты
- Исправление Critical/Blocker
- Повторный прогон

## 6. Критерии приёмки

- Все Blocker/Critical исправлены
- Не менее 80% тест-кейсов в статусе Passed после повторного прогона
- Unit-тесты запускаются и проходят
- Документация day7 сдана

## 7. Риски

| Риск | Митигация |
|------|-----------|
| Ошибка записи CSV на Android | Использовать `context.filesDir` |
| Эмулятор недоступен | Проверка ядра unit-тестами |
| Старый APK на устройстве | Uninstall + Clean Rebuild |
