# Руководство пользователя
## Приложение «Записная книжка контактов»

**Версия:** 1.0  
**Исполнитель:** Свиридова Диана Алексеевна  
**Дата:** 25.11.2026

---

## 1. Назначение

Мобильное приложение для хранения, поиска, редактирования и удаления контактов.  
Все данные хранятся локально на устройстве в файле CSV. Интернет не требуется.

---

## 2. Требования к устройству

| Параметр | Значение |
|----------|----------|
| ОС | Android 8.0 (API 26) и выше |
| Свободное место | ~10 МБ |
| Разрешения | Доступ к внутреннему хранилищу приложения (автоматически) |

---

## 3. Установка и запуск

1. Откройте проект в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Подключите устройство или запустите эмулятор (API 26+).
4. Нажмите **Run** или `Shift+F10`.
5. Приложение откроется на экране «Контакты».


---

## 4. Экраны приложения

### 4.1. Список контактов (главный экран)

- Заголовок «Контакты».
- Поле поиска вверху.
- Список карточек контактов.
- Кнопка **+** - добавить новый контакт.
- Пустое состояние: "Нет контактов. Нажмите + чтобы добавить".

### 4.2. Форма создания/редактирования

- Поля:
  - Имя * (обязательно)
  - Фамилия
  - Телефон * (обязательно)
  - Заметка
- Кнопки "Сохранить" и "Отмена".
- При ошибке валидации под полями появляется сообщение.

### 4.3. Детали контакта

- Полное имя, телефон, заметка, дата создания.
- Кнопки: "Редактировать", "Удалить".
- При удалении - диалог подтверждения.

---

## 5. Основные сценарии

### 5.1. Добавление контакта

1. На главном экране нажмите **+**.
2. Заполните **Имя** и **Телефон**.
3. При желании укажите фамилию и заметку.
4. Нажмите **Сохранить**.
5. Контакт появится в списке.

### 5.2. Поиск контакта

1. В поле поиска введите часть имени, фамилии или телефона.
2. Список обновится мгновенно.
3. Если ничего не найдено - сообщение «Ничего не найдено по запросу «…»».
4. Очистите поле - вернутся все контакты.

### 5.3. Просмотр и редактирование

1. Нажмите на карточку контакта.
2. Откроется экран деталей.
3. Нажмите **Редактировать**.
4. Измените данные и сохраните.

### 5.4. Удаление контакта

1. Откройте детали контакта.
2. Нажмите **Удалить**.
3. Подтвердите действие в диалоге.
4. Контакт исчезнет из списка.

---

## 6. Правила ввода данных

| Поле | Требования |
|------|------------|
| Имя | Не пустое, после обрезки пробелов |
| Телефон | От 10 до 15 цифр (допускаются пробелы, +, -, скобки - они удаляются при проверке) |
| Фамилия/Заметка | Необязательные |

При ошибке приложение **не сохраняет** контакт и показывает понятное сообщение.

---

## 7. Возможные сообщения об ошибках

| Ситуация | Сообщение |
|----------|-----------|
| Пустое имя | "Имя не может быть пустым" |
| Телефон < 10 цифр | "Телефон должен содержать не меньше 10 цифр" |
| Телефон > 15 цифр | "Телефон не должен содержать больше 15 цифр" |
| Ошибка записи файла | "Не удалось сохранить контакт: …" |
| Контакт не найден | "Контакт не найден" |

---

## 8. Хранение данных

- Данные сохраняются в файл `contacts.csv` внутри внутренней директории приложения.
- После перезапуска приложения все контакты остаются на месте.
- Экспорт/импорт CSV выполняется автоматически при каждом изменении.

---

## 9. Советы

- Для быстрого поиска достаточно ввести 2-3 символа.
- Перед удалением важного контакта убедитесь, что выбрали нужный.
- Приложение работает полностью офлайн.
